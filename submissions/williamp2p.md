**1. What is Blockchain?**
A shared digital record book copied across many computers. Records are grouped in "blocks" linked together in order. Once added, no one can secretly change it, because everyone's copy would have to match.
 
**2. Problems It Solves**
- No need for a middleman (bank, government) to verify deals
- Stops fraud/tampering with records
- Stops spending the same digital money twice
- Makes transactions transparent
- No single point of failure to hack
**3. Industries That Use It (examples)**
- **Finance** – Bitcoin, cross-border payments
- **Supply Chain** – Walmart tracks food from farm to store
- **Healthcare** – Secure, shareable patient records
- **Real Estate** – Fraud-proof property titles
- **Voting** – Tamper-proof election results
- **Art/Entertainment** – NFTs prove ownership of digital art
- **Insurance** – Auto-pay claims (e.g., flight delay refunds)
**4. What is Encryption?**
Turning readable data into scrambled code so only someone with the right key can read it. Like writing a secret message only you and a friend can decode.
 
**5. What is a Hash Function?**
A formula that turns any input into a fixed-length code (a "hash").
- Same input = same hash, always
- Tiny change in input = totally different hash
- Can't be reversed back to the original
Like a fingerprint — unique and can't rebuild the person from it.
 
**6. What is On-Chain?**
Anything recorded directly on the blockchain, permanently and visibly. (Opposite: "off-chain" = happens outside the blockchain.)
 
**7. Merkle Tree**
A way to combine lots of data into one single hash (the "Merkle Root") by hashing data in pairs, then hashing those results in pairs, and so on.
 
Lets you instantly know if any data was changed, without checking every piece one by one.
